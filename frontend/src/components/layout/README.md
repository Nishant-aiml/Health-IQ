# Structural Layout Components (`frontend/src/components/layout/`)

## What is this folder?
This folder holds the high-level structural components that wrap page views.

## Why does it exist?
To maintain consistent site navigation, header branding, API health status monitoring, theme toggles, and footers across all route views:
- **`Navbar.tsx`**: Header navigation bar with real-time API health status indicator.
- **`Footer.tsx`**: Page footer with system architecture information.
- **`RootLayout.tsx`**: Top-level layout container wrapping page content.
