# Reusable UI Primitives (`frontend/src/components/ui/`)

## What is this folder?
This folder contains generic, domain-agnostic UI component primitives designed for high visual aesthetics and accessibility.

## Why does it exist?
To establish a consistent UI design system (buttons, cards, inputs, containers, modals, tables, badges, loading spinners, alert boxes, empty states) without duplicating styling logic across pages:
- **`Container.tsx`**: Standardized page width wrapper.
- **`Button.tsx`**: Multi-variant button component.
- **`Card.tsx`**: Soft card container with header/footer support.
- **`Input.tsx`**: Styled form text input with error states.
- **`Modal.tsx`**: Accessible dialog overlay.
- **`Table.tsx`**: Responsive data table wrapper.
- **`Badge.tsx`**: Status indicator tags.
- **`Typography.tsx`**: Standardized heading and body text.
- **`LoadingSpinner.tsx`**: Animated processing spinner.
- **`ErrorAlert.tsx`**: Alert message box for exception surfacing.
- **`EmptyState.tsx`**: Placeholder illustration for empty data lists.
