# Application Page Views (`frontend/src/pages/`)

## What is this folder?
This folder houses full page views rendered by `react-router-dom`.

## Why does it exist?
Page components assemble generic UI primitives and layout structures to render distinct route views:
- **`HomePage.tsx`**: Main Phase 1 dashboard displaying backend health diagnostics and system version.
- **`LandingPage.tsx`**: Platform overview presenting core vision and architecture differentiators.
- **`AboutPage.tsx`**: Technical specification breakdown and technology stack overview.
- **`NotFoundPage.tsx`**: Standard 404 route handler.
- **`ErrorDemoPage.tsx`**: Interactive showcase of UI primitives, alert boxes, loading states, and modal dialogs.
